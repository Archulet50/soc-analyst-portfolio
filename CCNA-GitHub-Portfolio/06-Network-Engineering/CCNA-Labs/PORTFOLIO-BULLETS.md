# Portfolio and Résumé Language

## GitHub summary

Designed and validated five Cisco Packet Tracer labs covering VLAN segmentation, 802.1Q trunking, router-on-a-stick, single-area OSPF, DHCP, NAT/PAT, and extended ACL enforcement. Used Cisco IOS verification commands and systematic Layer 1–3 troubleshooting to isolate trunk-port mismatches, STP convergence behavior, addressing errors, routing gaps, and policy matches.

## Résumé bullets

- Built and validated five Cisco Packet Tracer labs spanning VLANs, 802.1Q trunking, inter-VLAN routing, OSPF, DHCP, NAT/PAT, and ACL-based security controls.
- Configured a three-router OSPF area 0 topology with `/30` transit networks, passive LAN interfaces, full neighbor adjacencies, and end-to-end dynamic routing.
- Implemented DHCP address allocation and PAT overload for multiple private endpoints sharing one public-facing IPv4 address; verified behavior through live translation tables and counters.
- Enforced least-privilege traffic rules with a named extended ACL, blocking device-specific ICMP and HTTP traffic while preserving approved connectivity.
- Diagnosed Layer 2 and Layer 3 faults using CDP, interface state, routing tables, packet tests, ACL counters, and NAT statistics.

## Interview talking point

“I built the labs progressively instead of treating each technology in isolation. VLANs established segmentation, router-on-a-stick added Layer 3 reachability, OSPF introduced dynamic routing, DHCP and PAT added network services, and the final ACL lab enforced a documented security policy. I deliberately verified both expected success and expected failure, then used show commands and hop-by-hop tests to resolve configuration and addressing issues.”
