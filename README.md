## CCNA Network Engineering Labs

Built and validated five Cisco Packet Tracer projects covering core switching, routing, network services, and security controls. Each lab includes the working `.pkt` file, addressing plan, Cisco IOS configuration highlights, verification commands, and troubleshooting findings.

| Project                                                                                                           | Skills demonstrated                                                   |
| ----------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| [VLANs and 802.1Q Trunking](CCNA-GitHub-Portfolio/06-Network-Engineering/CCNA-Labs/01-VLANs-Trunking/)            | VLAN creation, access ports, trunking, native VLANs, and STP          |
| [Inter-VLAN Routing](CCNA-GitHub-Portfolio/06-Network-Engineering/CCNA-Labs/02-Inter-VLAN-Routing/)               | Router-on-a-stick, subinterfaces, and default gateways                |
| [OSPF Multi-Router Network](CCNA-GitHub-Portfolio/06-Network-Engineering/CCNA-Labs/03-OSPF-Multi-Router-Network/) | OSPF area 0, `/30` links, neighbor adjacencies, and dynamic routes    |
| [DHCP and NAT/PAT](CCNA-GitHub-Portfolio/06-Network-Engineering/CCNA-Labs/04-DHCP-NAT-PAT/)                       | DHCP pools, exclusions, default routing, NAT, and PAT overload        |
| [ACL Network Security](CCNA-GitHub-Portfolio/06-Network-Engineering/CCNA-Labs/05-ACL-Network-Security/)           | Named extended ACLs, traffic filtering, placement, and match counters |
